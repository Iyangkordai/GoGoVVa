# Physical-Computing-Project-2026-IT-KMITL

## GoGoWa
## Abstract
โปรเจค ”โกโกวา“ เป็นการพัฒนาเกมบนระบบไมโครคอนโทรลเลอร์ Arduino เพื่อแก้ปัญหาสมาธิสั้นและฝึกปฏิกิริยาการยับยั้งชั่งใจ (Inhibitory Control) จากพฤติกรรมเสพสื่อสั้นในปัจจุบัน ตัวเกมถูกออกแบบมาเพื่อส่งเสริมพัฒนาการในเด็กและช่วยชะลอความเสื่อมของสมองในผู้สูงอายุ ผ่านกลไกการฝึกสมาธิและการประสานงานของระบบประสาท

ระบบทำงานด้วยโครงสร้าง Finite State Machine (FSM) ร่วมกับฟังก์ชันสุ่มเวลา โดยรับ Input จากการเลือกระดับความยากและการกดปุ่มควบคุม และส่ง Output ผ่านสัญญาณไฟ LED 3 สี เสียงเพลงประกอบ และหน้าจอLCD ผู้เล่นจะต้องกดปุ่มก้าวเดินในช่วงสัญญาณไฟเขียวและไฟเหลือง แล้วหยุดกดปุ่มทันทีเมื่อเข้าสู่สัญญาณไฟแดง โดยหากกดพลาดระบบจะเปลี่ยนเป็น Game Over ทันที ซึ่งกลไกนี้จะช่วยกระตุ้นให้สมองเกิดการเรียนรู้ในการควบคุมตนเองและการจดจ่อได้อย่างมี



## อุปกรณ์ที่ใช้
Arduino board (1)
Breadboard (1)
LCD 16x2 I2C (1)
Switch (1)
Potentiometer (1)
LED RGB (1)

## Input & Output
Input
1. ปุ่มกด (Push Button): สำหรับกดเลือกเริ่มเกมและกดเพื่อก้าวเดิน
2. ตัวต้านทานปรับค่าได้ (Potentiometer): เลือกระดับความยาก 

Output 
1. LED แสดงสภาวะการเล่นแบบเรียลไทม์ (เขียว = เดิน / เหลือง = เตือน / แดง = หยุด)
2. สัญญาณเสียง (Buzzer) ส่งเสียงเพลงประกอบและสุ่มเปลี่ยนความเร็วเพลงตามระดับความยาก
3. หน้าจอ LCD (16x2 I2C) แสดงผลแพ้-ชนะและคะแนนที่ได้เมื่อจบเกม (WIN / GAME OVER)

## How to play
1. หมุน Potentiometer เพื่อเลือกระดับความยากที่ต้องการ (Easy, Medium, Hard) 
2. กดคลิกที่ Button เพื่อยืนยันและเข้าสู่หน้าจอเกมหลัก (Main Game) 
3. กด Button ให้เร็วที่สุดเท่าที่จะทำได้ เฉพาะตอนที่เพลงกำลังเล่นอยู่เท่านั้น เพื่อให้ตัวละครบนจอ LCD เดินไปจนถึงเส้นชัย 
4.หากเผลอกด Button ในจังหวะที่เพลงหยุด (เพลงดับ) เกมจะ Game Over ทันที 
5. เมื่อกดปุ่มจนตัวละครเดินถึงเป้าหมายสำเร็จ เกมจะพาไปยังหน้าจอแสดงผลคะแนนของคุณ
