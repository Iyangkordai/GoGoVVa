บทคัดย่อ

โปรเจค ”โกโกวา“ เป็นการพัฒนาเกมบนระบบไมโครคอนโทรลเลอร์ Arduino เพื่อแก้ปัญหาสมาธิสั้นและฝึกปฏิกิริยาการยับยั้งชั่งใจ (Inhibitory Control) จากพฤติกรรมเสพสื่อสั้นในปัจจุบัน ตัวเกมถูกออกแบบมาเพื่อส่งเสริมพัฒนาการในเด็กและช่วยชะลอความเสื่อมของสมองในผู้สูงอายุ ผ่านกลไกการฝึกสมาธิและการประสานงานของระบบประสาท

ระบบทำงานด้วยโครงสร้าง Finite State Machine (FSM) ร่วมกับฟังก์ชันสุ่มเวลา โดยรับ Input จากการเลือกระดับความยากและการกดปุ่มควบคุม และส่ง Output ผ่านสัญญาณไฟ LED 3 สี เสียงเพลงประกอบ และหน้าจอ LCD ผู้เล่นจะต้องกดปุ่มก้าวเดินในช่วงสัญญาณไฟเขียวและไฟเหลือง แล้วหยุดกดปุ่มทันทีเมื่อเข้าสู่สัญญาณไฟแดง โดยหากกดพลาดระบบจะเปลี่ยนเป็น Game Over ทันที ซึ่งกลไกนี้จะช่วยกระตุ้นให้สมองเกิดการเรียนรู้ในการควบคุมตนเองและการจดจ่อได้อย่างมีประสิทธิภาพ

จุดเด่น

ฟังเสียง ไม่ใช่แค่ดูไฟ: ใช้ความเงียบของเพลงเป็นสัญญาณหยุด ผู้เล่นต้องฟังและยับยั้งตัวเองทันที เป็นการฝึกสมาธิและการควบคุมตนเองแบบ Go/No-Go

จังหวะคาดเดาไม่ได้: สุ่มความเร็วเพลงและเวลาเงียบในแต่ละรอบ จึงจำจังหวะล่วงหน้าไม่ได้

ความยากปรับได้จริง: 3 ระดับที่เปลี่ยนทั้งระยะทาง ความเร็วเพลง และตัวช่วย (Easy มีไฟเตือนก่อนเพลงดับ)

คะแนนตามฝีมือ: คิดจากความเร็วและระดับความยาก ชวนให้เล่นซ้ำเพื่อทำลายสถิติ

แอนิเมชันบนจอ LCD 16x2: ตัวละครก้าวเดินทุกครั้งที่กด และตุ๊กตา GoGoWa หันหัวตามจังหวะเพลง

วิธีเล่น

1. หมุน Potentiometer เพื่อเลือกระดับความยากที่ต้องการ (Easy, Medium, Hard)

2. กดคลิกที่ Button เพื่อยืนยันและเข้าสู่หน้าจอเกมหลัก (Main Game)

3. กด Button ให้เร็วที่สุดเท่าที่จะทำได้ เฉพาะตอนที่เพลงกำลังเล่นอยู่เท่านั้น เพื่อให้ตัวละครบนจอ LCD เดินไปจนถึงเส้นชัย

4.หากเผลอกด Button ในจังหวะที่เพลงหยุด (เพลงดับ) เกมจะ Game Over ทันที

5. เมื่อกดปุ่มจนตัวละครเดินถึงเป้าหมายสำเร็จ เกมจะพาไปยังหน้าจอแสดงผลคะแนนของคุณ
